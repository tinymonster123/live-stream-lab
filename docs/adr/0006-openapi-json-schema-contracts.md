# Define cross-language contracts in OpenAPI 3.1 and JSON Schema

Status: accepted

HTTP and WebSocket payloads are defined in OpenAPI 3.1; AI Job, Transcript, and Artifact payloads in JSON Schema. Go uses `oapi-codegen`, TypeScript uses `openapi-typescript`, and Python uses Pydantic. This keeps one source of truth without a protobuf/gRPC toolchain.

## Considered Options

- **Protobuf/gRPC**: overkill for a local JSON pipeline and adds a toolchain.
- **TypeScript types as the source**: excludes Go and Python from the contract.

## Consequences

- `libs/contracts` is the only place payload shapes are defined.
- Generated code is checked in or regenerated by an Nx target; do not hand-edit generated types.
